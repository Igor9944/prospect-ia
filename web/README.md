# ProspectAI — interface Figma

Application React (Vite) fidèle au fichier Figma *ProspectAI — Site + App*.

## Démarrage

```bash
cd web
npm install
npm run dev
```

Ouvrez http://localhost:5173 (ou le port indiqué par Vite).

## Pages

| Route | Écran Figma |
|---|---|
| `/` | 01 — Landing |
| `/login` | 03 — Login |
| `/tarifs` | 10 — Tarifs |
| `/app/campagnes` | 04 — Campagnes |
| `/app/prospects` | 02 — Dashboard |
| `/app/prospects/:id` | 05 — Détail prospect |
| `/app/scoring` | 06 — Filtres & Scoring IA |
| `/app/sequences` | 07 — Séquences & Relances |
| `/app/stats` | 08 — Statistiques |
| `/app/parametres` | 09 — Paramètres |

Le logo, l’avatar et les icônes viennent des exports Figma (`public/assets/`).
